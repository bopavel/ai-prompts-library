# First Draft Protector

**Best For**: 
- Fiction writers struggling to finish first drafts
- Anyone who gets stuck in endless revision cycles
- Writers with perfectionist tendencies
- Creating initial content before refinement (blog posts, reports, scripts)

---

## Customization Guide

### Adjust Intervention Intensity

**For Heavy-Handed Protection (Maximum Redirects)**:
```
Add after CORE PHILOSOPHY:
"Intervention level: HIGH - Stop any editing attempt immediately, even mid-sentence"
```

**For Gentle Guidance (Minimal Interruption)**:
```
Modify to:
"Intervention level: LOW - Only redirect after multiple editing attempts"
```

---

### Modify Encouragement Style

**For Tough-Love Approach**:
```
Replace ENCOURAGEMENT FRAMEWORK with:
"Be direct and challenging. Less cheerleading, more accountability.
'You're editing again. You know better. Keep writing.'"
```

**For Maximum Cheerleading**:
```
Add:
"Celebrate every 100 words with enthusiasm. Use emojis. Be their biggest fan."
```

---

### Adapt for Different Formats

**For Academic Writing**:
```
Add after TRACKING:
"Academic-specific: Allow [CITE] and [REF] placeholders but no actual citation lookup during drafting"
```

**For Screenwriting**:
```
Add:
"Focus on dialogue and action. Treat scene descriptions as bare-bones placeholders.
Redirect any cinematography or staging concerns to later revisions."
```

**For Business Writing**:
```
Add:
"Track key points covered vs. outline. Allow bullet points as draft mode.
Redirect any tone-polishing until draft is complete."
```

---

### Adjust Word Count Celebrations

**For Long-Form Projects (Books)**:
```
Modify ENCOURAGEMENT FRAMEWORK:
"Celebrate every 500 words. Track chapter completion as major milestones."
```

**For Short-Form Content**:
```
"Celebrate every 100 words. Track paragraph completion."
```

---

### Integration with Tools

**With Writing Apps (Notion, Google Docs)**:
```
Add:
"Suggest [BRACKET] notation for all edit notes so they're searchable later.
Example: [IMPROVE: make this more specific] [FACT-CHECK] [REPHRASE]"
```

**With Time Tracking**:
```
Add:
"Track writing sessions. Celebrate streak days.
After each session, summarize: 'Session X: [Y] words in [Z] minutes = [W] words/min'"
```

## Limitations & Edge Cases

### Won't Work Well For

**Technical Documentation Requiring Precision**:
- **Why**: Safety-critical or legally binding content can't use "good enough" approach
- **Alternative**: Use structured technical writing prompt with built-in verification

**Quick Edits to Nearly-Complete Work**:
- **Why**: Overkill when you genuinely just need to fix a typo
- **Alternative**: Use "edit mode" from the start or skip this prompt

**Collaborative Writing with Real-Time Feedback**:
- **Why**: Conflicts with co-authors who need to review as you go
- **Alternative**: Write async first, then share

**Poetry or Highly Stylistic Writing**:
- **Why**: Word choice and rhythm are often part of the creative discovery
- **Alternative**: Modified version that allows "exploratory revision" within sections

---

### Common Pitfalls

**Pitfall 1: Using for Wrong Writing Phase**
- **Symptom**: You have a complete draft but prompt won't let you revise
- **Solution**: Clear exit command: Say "draft complete, switch to edit mode"

**Pitfall 2: Too Much Encouragement Feels Condescending**
- **Symptom**: Cheerleading feels annoying rather than motivating
- **Solution**: Customize: "Encouragement style: minimalist. Just track numbers, skip commentary"

---

### Edge Cases

**Edge Case 1: Writing Out of Order**
- **How prompt handles it**: Supports jumping around with [FILL THIS LATER] placeholders
- **Recommendation**: Works well, just track which sections are complete vs. placeholders

**Edge Case 2: Discovery Writing (No Outline)**
- **How prompt handles it**: Excellent fit, emphasizes forward momentum over structure
- **Recommendation**: Let the draft be messy; structure emerges in editing

**Edge Case 3: Dictation or Voice Writing**
- **How prompt handles it**: May need modified encouragement (voice produces more volume)
- **Recommendation**: Adjust milestones to every 500 words instead of 250

**Edge Case 4: Severe Writer's Block (Can't Write Anything)**
- **How prompt handles it**: Offers "write one terrible sentence" approach
- **Recommendation**: May need separate anti-block strategies first, then use this for momentum

## Advanced Usage

### Progressive Draft Phases

**Phase 1: Brain Dump (This Prompt)**
```
Get everything out messily. Speed over quality.
Goal: Complete, terrible first draft
```

**Phase 2: Structural Edit (Different Prompt)**
```
Move sections, cut unnecessary parts, clarify flow.
Don't touch sentence-level writing yet.
```

**Phase 3: Line Edit (Different Prompt)**
```
Now fix sentences, improve word choice, polish.
```

---

### Combining with Accountability

**Add to prompt**:
```
"At session end, ask: 'When is your next writing session?'
Track commitments. Next session, remind me: 'You committed to writing today. Ready?'"
```

---

### Power User: Custom Momentum Triggers

**Add personalized motivation**:
```
"When I hit 500 words, remind me: '[Personal mantra]'
When I try to edit, say: '[Tough love phrase I respond to]'
When I complete a section: '[Celebration ritual]'"
```
