# Assumption Challenger

**Best For**: 
- Early-stage research design (before committing to methodology)
- Literature review analysis (finding gaps in existing assumptions)
- Hypothesis refinement (stress-testing your claims)
- Grant proposal development (anticipating reviewer concerns)
- Interdisciplinary research (surfacing domain-specific assumptions)

---

## Customization Guide

### Adjust Challenge Intensity

**For Gentle Questioning (Early Ideas)**:
```
Add after CORE PRINCIPLES:
"Challenge softly - the researcher is exploring. Focus on major assumptions only."
```

**For Rigorous Critique (Pre-Submission)**:
```
Modify to:
"Challenge intensity: HIGH. This needs to withstand peer review. Be thorough and skeptical."
```

---

### Domain Specialization

**For Social Sciences**:
```
Add:
"Prioritize questions about construct validity, sampling representativeness, 
and alternative theoretical frameworks (positivist vs. interpretivist)."
```

**For Natural Sciences**:
```
Add:
"Focus on experimental controls, measurement precision, replicability concerns,
and confounding variables."
```

**For Humanities**:
```
Add:
"Question interpretive frameworks, canon assumptions, and whose perspectives 
are centered vs. marginalized."
```

---

### Adjust for Research Stage

**For Early Exploration**:
```
"Focus on big-picture assumptions (scope, definitions, frameworks).
Skip methodological details - those come later."
```

**For Methodology Design**:
```
"Prioritize methodological and data assumptions. Test whether method fits question."
```

**For Results Interpretation**:
```
"Focus on inferential assumptions: What do these results actually show? 
What alternative explanations exist?"
```

---

### Combine with Support

**For Defensive Researchers**:
```
Add:
"Begin each challenge with validation: 'Your thinking on X is solid. Now let's 
pressure-test Y...'"
```

**For Stuck Researchers**:
```
Add:
"If researcher seems paralyzed by critique, shift to: 'Here's how to address 
this concern...' and provide concrete solutions."
```

## Limitations & Edge Cases

### Won't Work Well For

**Late-Stage Research (Data Already Collected)**:
- **Why**: Many assumptions are already locked in by methodology
- **Alternative**: Use for interpreting results within constraints

**Pure Theoretical Work**:
- **Why**: Philosophers intentionally explore assumptions; this might be redundant
- **Alternative**: Focus on internal logical consistency instead

---

### Common Pitfalls

**Pitfall 1: Challenging Everything to Paralysis**
- **Symptom**: Researcher feels unable to proceed because everything is questioned
- **Solution**: Triage assumptions - some must be taken for granted to do any research. Focus on testable ones.

**Pitfall 2: Critique Without Construction**
- **Symptom**: Only problems identified, no solutions offered
- **Solution**: Follow every major challenge with "Here's how to address it..."

**Pitfall 3: Assuming Researcher Background**
- **Symptom**: Challenges using jargon or concepts the researcher doesn't know
- **Solution**: Ask about expertise level upfront, adjust accordingly

**Pitfall 4: Treating All Assumptions as Equal**
- **Symptom**: Minor definitional choice gets same scrutiny as causal claim
- **Solution**: Use escalation ladder - flag minor ones, deeply explore foundational ones

---

### Edge Cases

**Edge Case 1: Interdisciplinary Research**
- **How prompt handles it**: Questions assumptions from multiple disciplinary perspectives
- **Recommendation**: Extremely valuable here - surfaces where disciplines clash

**Edge Case 2: Replication Studies**
- **How prompt handles it**: Questions whether original assumptions should be preserved or updated
- **Recommendation**: Useful for "should we change X from original?" decisions

**Edge Case 3: Applied Research with Fixed Constraints**
- **How prompt handles it**: Can challenge within constraints (e.g., "Given you must use survey data...")
- **Recommendation**: Clarify immovable constraints upfront

**Edge Case 4: Researcher Has Already Considered Assumption**
- **How prompt handles it**: Ask them to articulate their reasoning, which often reveals gaps
- **Recommendation**: Still valuable - explaining assumptions strengthens writing

## Advanced Usage

### Pre-Grant Review
```
Add:
"Take the perspective of a skeptical grant reviewer. What assumptions would 
make them doubt feasibility or impact? How can I preempt these concerns?"
```

---

### Assumption Mapping
```
"For each assumption challenged, create a diagram:
ASSUMPTION → DEPENDS ON → EVIDENCE FOR → IF WRONG, THEN"
```

---

### Collaborative Critique
```
"I'm working with a co-author. Question my assumptions, then question theirs, 
then find where our implicit assumptions conflict."
```
