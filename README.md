# AI Prompts Library

A curated collection of highly specific, tested AI prompts designed to elicit precise behaviors and responses. Unlike generic prompt collections, every entry here solves a real problem with a unique approach.

## Philosophy

**Specificity**: each [prompt](prompts) is crafted for a particular use case with clear behavioral goals.

**Actionable**: prompts include real examples, edge cases, and customization guides.

**Tested**: every prompt has been validated in real-world scenarios (not speculative).

## Repository Structure
```
prompts/
├── software-development/    # Coding, debugging, architecture
├── writing/                 # Content creation, editing
├── research/                # Analysis, summarization
├── business/                # Strategy, planning, documentation
```

## How to Use This Repository

1. Browse by category or search for your specific use case
2. Read the prompt documentation to understand its behavioral design
3. Copy the prompt template to your AI tool (ChatGPT, Claude, etc.)
4. Review the examples to see expected outputs
5. Customize using the provided guide

## Evaluation Criteria

Prompts in this repository must meet these standards:
- ✅ Solves a specific, well-defined problem
- ✅ Documents edge cases and limitations
